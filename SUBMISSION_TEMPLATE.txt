一、專案簡介
SellerMate 是為中小型電商賣家設計的經營分析網站，包含模擬資料儀表板、商品利潤與保本售價計算、多商品 CSV 匯入與比較。使用 HTML、CSS、JavaScript 製作，所有計算由程式執行，並可透過 GitHub Pages 公開瀏覽。網站目前為靜態前端版本，尚未串接即時 AI；未來可整合已開發的 SellerMate Tool Use Agent。

七、延伸性與限制
網站以 AGENTS.md 規範 AI 後續開發，程式使用可重用模組，並包含公式與 CSV 自動測試。模擬資料不代表真實商店表現；網站為靜態前端，沒有在公開程式碼中放入 API 金鑰。若未來整合 Groq AI Agent，將使用安全後端處理金鑰及資料隱私。
