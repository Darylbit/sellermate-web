ABOUT THE PROJECT

讓 AI 開發規則，成為可延伸的產品基礎

SellerMate 是為中小型電商商家打造的經營分析網站，也是一次以 AGENTS.md 指導 AI 開發的實作。

01 · 真正可用

利潤計算、目標定價、CSV 匯入、商品比較與指標展示均為實際 JavaScript 功能，而非靜態圖片。

02 · 規則可重用

AGENTS.md 明確規定技術架構、計算公式、資料格式、共用元件與測試流程，方便 AI 後續修改。

03 · 可以延伸

後續可新增圖表、報表頁、商品分群，以及透過安全後端串接真正的 Tool Use AI Agent。

網站架構與技術

為 GitHub Pages 而設計的無建置步驟網站

HTML / CSS
四個頁面、共用導覽、響應式版型與無障礙標籤。
JavaScript 模組
核心計算與 CSV 解析集中在 js/core.js，頁面互動集中在 js/app.js。
AGENTS.md 與測試
規範未來開發，並用 Node.js 測試公式、邊界條件與 CSV 匯入。
GitHub Pages
靜態部署，公開網址可正常瀏覽，無須後端服務。

未來如何交給 AI 繼續開發？

以新增「月度報表頁」為例

先閱讀 AGENTS.md
理解網站目的、資料定義、頁面架構與設計規範。
建立新頁面
沿用共用導覽與 CSS，不重複撰寫公式。
增加測試
新指標需新增單元測試，確認既有功能未受影響。
同步更新說明
更新 README、部署後逐頁驗證手機與桌面顯示。

與期末 AI Agent 的關係

這次作業完成的是可以公開瀏覽的前端分析平台。之前的 SellerMate Tool Use Agent 原型曾透過 Python 與 Groq 進行工具呼叫，但本網站尚未連接該服務。未來若整合 AI 問答，需要安全後端保存 API 金鑰、限制請求及處理資料隱私，不能把金鑰放在 GitHub Pages 公開程式碼中。

誠實揭露：網站上的預設營收與訂單均為模擬資料，所有財務計算僅供示範與初步決策參考。
